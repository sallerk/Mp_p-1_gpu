# ===========================================================================
#  worktodo.txt -- the exponent queue
#
#  One line per job, top to bottom. Mp_p-1_gpu works the first line, removes
#  it once that job is done (found a factor or not -- either way, the result
#  is in results.txt), then moves to the next. '#' starts a comment; blank
#  lines are ignored -- same convention as config.txt.
#
#  A line is either a bare exponent:
#
#    82589933
#
#  or a Pfactor=/Pminus1=/Pplus1= assignment, the shape AutoPrimeNet
#  (github.com/tdulcet/AutoPrimeNet) and Prime95 itself write, e.g.:
#
#    Pminus1=1,2,82589933,-1,1000000,30000000
#
#  Both accept an optional leading assignment ID (32 hex chars, comma-
#  terminated). A Pminus1= line's own B1/B2 are used whenever present; a
#  Pfactor= line or a bare exponent has none, and falls back to config.txt's
#  own b1/b2. See MANUAL.md for the full field list of each shape.
#
#  Entries run under config.txt's settings (bias, stages, ...) -- only the
#  exponent, and whatever an assignment line itself supplies (bounds,
#  how-far-factored, known factors), varies per entry.
#
#  `method` is the exception: a Pminus1= line runs P-1 and ONLY P-1, and a
#  Pplus1= line runs P+1 and ONLY P+1, whatever config.txt says. The line
#  names the work, so the line wins. A Pfactor= line and a bare exponent
#  name no method and use config.txt's `method` as before.
#
#  If a job is interrupted (Ctrl+C, or the program is killed), its line
#  stays here untouched -- relaunching resumes that exponent from its
#  checkpoint, then continues down the queue from there.
#
#  If a job FAILS (an error, not "no factor found" -- e.g. an exponent too
#  small for any FFT shape to hold), the whole queue stops there and that
#  line is left in place too, so you can fix or remove it before continuing.
#
#  MINIMUM EXPONENT: 786613. Below that, even the smallest FFT shape in the
#  catalog (256x256x2) has too few bits/word to be usable, and every command
#  -- --bounds, --tune, a real run -- just fails with "no FFT fits this
#  exponent".
# ===========================================================================
